# Frontend — tp-productos (React + TypeScript + Tailwind)

Maquetado sin hooks ni llamadas a API.

## Estructura

```
src/
├── components/   Navbar, ProductoCard, ProductoList, ProductoForm, Footer
├── types/        producto.ts
├── App.tsx
└── main.tsx
```

## Comandos

```bash
cd frontend
pnpm install
pnpm dev
```

También funciona con `npm install` y `npm run dev`.
