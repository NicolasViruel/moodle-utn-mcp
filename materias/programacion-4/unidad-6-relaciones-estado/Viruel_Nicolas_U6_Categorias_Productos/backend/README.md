# Backend — CRUD Categorías + Productos

**Alumno:** Nicolás Viruel — Programación IV — Unidad 6

## Requisitos

- Python 3.11+

## Instalación

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Ejecutar

Desde esta carpeta (`backend/`):

```bash
python -m fastapi dev app/main.py
```

Documentación: http://127.0.0.1:8000/docs

## REST Client

Ver `tests/productos.http` para probar productos y relaciones N:N.
