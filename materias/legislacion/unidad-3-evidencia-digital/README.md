| Archivo | Descripción |

## Cómo usar la guía

1. Abrí el cuestionario en Moodle.
2. Para cada pregunta, buscá el tema en `guia-practica.md` o mandame la pregunta con las opciones y te digo cuál marcar.
3. Enviá el intento cuando termines (podés reintentar si la nota no te convence).

- Actividad II (jurisprudencia hash) + cuestionario
